# LCF · UPLA — Sitio web

Sitio estático del **Laboratorio de Investigación en Cómputo de Física, Universidad de Playa Ancha**.

- `index.html` — portada; áreas, investigadores, cinco espacios para estudiantes, fotografía institucional y contacto.
- `cosmologia.html` — publicaciones seleccionadas de Manuel González-Espinoza y enlace a INSPIRE.

- `optica.html` — publicaciones seleccionadas de Leandro Núñez Arratia y enlace a Google Scholar.

`https://www.upla.cl/investigacion/wp-content/uploads/2026/06/Leandro-Nulez-LFC-UPLA.jpeg`

## Publicar / actualizar en GitHub Pages

Repositorio: `https://github.com/manuelgonzalez-upla/lcf-upla`

1. En el repositorio abre **Add file → Upload files**.
2. Sube **todos los archivos** de esta carpeta (sin subir el ZIP ni una carpeta contenedora).
3. Marca la confirmación con **Commit changes**.
4. Si ya activaste Pages en **Settings → Pages → main → /(root)**, GitHub publicará la versión actualizada en `https://manuelgonzalez-upla.github.io/lcf-upla/`.

Para actualizaciones posteriores, solo necesitas reemplazar los HTML o CSS modificados y confirmar el commit.
