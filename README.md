# Sitio web LCF · UPLA

Sitio web estático de una sola página. La fotografía se carga directamente desde el servidor de la UPLA.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `lcf-upla`.
2. Sube el archivo `index.html` a la raíz del repositorio.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**. Guarda.
5. El sitio quedará disponible en `https://TU_USUARIO.github.io/lcf-upla/`.

Para verlo localmente solo abre `index.html` con un navegador.
